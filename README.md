MotionLab

Landing page de um estúdio fictício de motion design, animação 2D e identidade visual, criada do zero com HTML e CSS como projeto de estudo de front-end.

Sobre o projeto

O MotionLab apresenta um estúdio criativo para marcas que não querem ficar paradas. O foco do projeto foi praticar estrutura semântica, layout com Flexbox, tipografia responsiva e estilização de detalhes com CSS.

Seções

- Apresentação: título de destaque, subtítulo e chamadas para ação
- Serviços: cards de Motion Design, Animação 2D e Identidade Visual
- Contato

Tecnologias

- HTML5
- CSS3 (Flexbox, unidades `vw` e `em`)
- Google Fonts (Poppins e Caveat)
